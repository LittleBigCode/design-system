Charts

Six of the eight charts are React-only from 1.0.0-beta.4 on: line, area, bar, stacked bar, pie and donut draw their marks with recharts, so there is no markup that reproduces them and no class per mark. What the stylesheet owns is the frame — .ds-chart-container, .ds-chart-tooltip-content and .ds-chart-legend-content — plus the descendant rules that repaint recharts' hard-coded #ccc gridlines and #fff outlines onto --ds-* tokens. Each of the six is documented, with a live playground, in the React workbench.

The gauge below and the sparkline stay library-free — one arc pair and one polyline, drawable by hand — so they are the two charts a non-React binding can still render. 0.11's pure-SVG .ds-chart, .ds-linechart, .ds-areachart, .ds-donut, .ds-piechart, .ds-stackedbar and .ds-barchart classes were removed in the same release; from-0.11.md maps every one.

Gauge

A .ds-gauge draws a faint 270° -track arc behind a coloured -value arc (length via stroke-dasharray, so the arc redraws without recomputing its path), with a big -center number and an optional uppercase -label. The arc colour defaults to --ds-chart-1; pass a colour or value→colour thresholds.

The frame

These three classes are what a recharts chart lands in, and the only chart classes a consumer writes by hand. .ds-chart-container is a 16/9 box; --plot swaps that for a fixed height and full width (the axis charts), --square for a 1:1 box (pie, donut), and both read --ds-chart-height — the knob that replaced the source's Tailwind height literals.

The six React charts 
// recharts is an optional peer dependency, like react:
//   npm i recharts
import {
  LineChart, AreaChart, BarChart, StackedBar, PieChart, DonutChart,
} from "@diametral/design-system/react";

const config = {
  signups: { label: "Signups", color: "var(--ds-chart-2)" },
  churn: { label: "Churn" },   // takes the next --ds-chart-* slot
};

<LineChart config={config} data={rows} xAxisKey="week" />
<BarChart config={config} data={rows} xAxisKey="week" max={300} horizontal />

            centerLabel="8.2 GB" centerCaption="of 10 GB" />
